# Studio Visite

Application web pour créer une visite virtuelle à partir de vraies photos d'un lieu (restaurant, appartement, boutique…).

- Photos 360° ou panoramas de téléphone : une photo = une pièce
- Points de passage entre les pièces, plan et mini-carte
- Pièce 3D : dimensions + photos des murs, du sol et du plafond, redressées en plaçant les 4 coins
- Export d'une visite autonome (un seul fichier HTML) à mettre en ligne et partager

Tout fonctionne dans le navigateur : les photos restent sur l'appareil, aucun serveur n'est nécessaire.
